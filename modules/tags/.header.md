# AWS Tags Terraform Module

Generic, reusable Terraform module for FOCUS 1.2+ compliant AWS tag composition.

## Features

- 8-tag taxonomy: Application, Service, Environment, Owner, CostCenter, ManagedBy, Compliance, DataClassification
- Input validation for all enum and pattern fields
- `null_resource` lifecycle precondition verifies all 8 tags are non-empty at plan time
- Designed for injection via provider `default_tags` — one module call per root

## Basic Usage

```hcl
module "tags" {
  source = "../modules/tags"

  environment      = "dev"
  application      = "my-platform"
  service          = "backend"
  owner            = "platform-team@example.com"
  cost_center      = "CC-PLATFORM-001"
  compliance       = "n/a"
  data_classification = "internal"
}

provider "aws" {
  default_tags {
    tags = module.tags.common_tags
  }
}
```

# AWS AppRegistry Terraform Module

Generic, reusable Terraform module for AWS Service Catalog AppRegistry application registration.

## Features

- Registers an application in AWS AppRegistry for `awsApplication` tag auto-propagation
- Count-guard for LocalStack compatibility (`enable_appregistry = false` → count = 0)
- Exposes `application_tag` output for resource-level tag injection via `additional_tags` (NOT `provider.default_tags` — that raises a Terraform cycle)
- No customer-specific values baked in — all inputs are variables with sensible defaults

## Basic Usage

```hcl
module "appregistry" {
  source = "../modules/appregistry"

  enable_appregistry = true
  application_name   = "my-platform"
}

# Provider default_tags carries ONLY static Tier 1-4 tags (e.g. module.tags.common_tags).
# Do NOT put module.appregistry.application_tag here — provider config is evaluated
# statically at plan time; referencing a module output raises a Terraform cycle.
provider "aws" {
  default_tags {
    tags = local.common_tags
  }
}

# Propagate the awsApplication tag at RESOURCE level via additional_tags.
# Returns {} when enable_appregistry=false — merge() is a no-op.
module "s3_bucket" {
  source          = "../modules/s3"
  additional_tags = try(module.appregistry.application_tag, {})
  # ...
}
```

## LocalStack Compatibility

`servicecatalog-appregistry` is not available in LocalStack Community edition.
Set `enable_appregistry = false` when targeting LocalStack — the module creates zero
resources and `application_tag` returns `{}`. Pass it at resource level via
`additional_tags = try(module.appregistry.application_tag, {})` — the merge is a no-op when the
value is empty. Never put it in `provider.default_tags` (cycle, even in LocalStack).

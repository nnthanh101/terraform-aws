# AWS Foundation Terraform Module

Generic, reusable Terraform module for core AWS workload infrastructure.

## Features

- S3 media bucket (versioned, SSE-AES256, public access blocked)
- Secrets Manager secrets for application runtime credentials (DATABASE_URL, REDIS_URL, JWT_SECRET, COOKIE_SECRET)
- SQS event bus queue with dead-letter queue (SQS-managed SSE)
- SNS event bus topic (AWS-managed KMS key) with SQS subscription
- All resources inherit tags from provider `default_tags`; per-resource overrides use `Service` tag
- LocalStack Community-compatible (all resources use managed keys, no CMK dependency)

## Basic Usage

```hcl
module "foundation" {
  source = "../modules/foundation"

  environment            = "dev"
  name_prefix            = "myapp"
  secret_recovery_window = 7
}
```

## Design Notes

- **State bucket excluded**: Terraform state bucket is provisioned by a separate bootstrap root to
  avoid the self-referential state deadlock. This module owns workload-layer resources only.
- **No CloudWatch log groups**: Use AWS Managed Prometheus + Grafana for observability (vendor-neutral).
- **secret_recovery_window = 0** for local/dev environments (instant delete); set >= 7 for prod.
